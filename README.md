**Golden Ladle Bistro** — a rush-hour cooking game. Run a tiny bistro for one 150-second day: take tickets off the order board, grill patties on two burners (don't let them burn), chop tomato, lettuce and onion on the board, stack each plate to match its ticket, and ring the bell to serve before the ticket's patience runs out. Combos pay extra, walk-outs cost hearts, and the tickets arrive faster as the day goes on. Keyboard (1–6 for ingredients, Space to serve, C to chop, G to take from the grill) and mouse both work. Everything is drawn with canvas shapes — no images, no network, no build step.

## Run it

```sh
cd game && python3 -m http.server 8080
```

Then open http://localhost:8080 in desktop Chrome and click **Start the Day**.
